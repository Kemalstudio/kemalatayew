1. Используемые технологии (Стек)
    React: Основа интерфейса.
    GSAP & ScrollTrigger: «Тяжелая артиллерия» для анимаций при скролле.
    Framer Motion: Для плавного появления элементов (AnimatePresence) и простых переходов.
    Lenis: Для «мягкого» скролла (Smooth Scroll), как на сайтах Apple.
    Matter.js: Физический движок для создания гравитации и столкновений.
    Spline: Интеграция реальной 3D-сцены.
    React Spring: Физически-ориентированная анимация для кнопок.
    Lottie: Легкая векторная анимация (иконка скролла).

2. Подготовка и Утилиты (Начало кода)
    Мультиязычность (translations)
    Объект содержит тексты на трех языках (EN, RU, TK). Это позволяет приложению мгновенно менять язык без перезагрузки страницы через состояние lang.
    Плавный скролл (SmoothScroll)
    Компонент инициализирует Lenis. Он перехватывает стандартный скролл браузера и делает его инерционным и плавным. Это критично для того, чтобы анимации GSAP выглядели синхронно с движением колесика мыши.
    Кастомный курсор (CustomCursor)
    Курсор состоит из двух частей: точки и «преследователя» (follower).
    Используется gsap.quickTo — это самый быстрый способ обновлять координаты мыши без лагов.
    Реализована логика data-cursor: если навести на элемент с таким атрибутом, курсор расширяется и показывает текст.
    Магнитный эффект (Magnetic)
    Обертка, которая заставляет элементы (например, кнопки) притягиваться к курсору, когда он находится рядом. Используется физика elastic.out для эффекта пружины.

3. Основные компоненты (Секции сайта)
    Прелоадер (LoadingScreen)
    Имитирует загрузку от 0 до 100%. Когда прогресс достигает конца, вызывается onComplete, который открывает основной контент. Это нужно, чтобы тяжелые 3D-модели и видео успели прогрузиться в кэш.
    Hero-секция (Главная)
    Spline: Вставляется 3D-сцена (компьютер или абстракция).
    SplitText: Разбивает заголовок на буквы, чтобы анимировать каждую отдельно (эффект появления из небытия).
    Parallax Orbs: Сферы на фоне, которые слегка двигаются за мышкой, создавая глубину.
    Эффект Gigabyte (GigabyteScrollEffect)
    Сложная анимация со ScrollTrigger:
    Pinning: Секция «застывает» на месте, пока вы крутите скролл.
    Morphing: Текст меняет прозрачность, масштаб и цвет. Мы видим, как фраза «I Develop Applications» превращается в «FULL STACK is My Playground».
    Bento Grid (TechBentoGrid)
    Сетка в стиле Apple/Microsoft.
    TiltCard: Карточки наклоняются в 3D в зависимости от положения мыши.
    Proximity Glow: В CSS настроен эффект, когда под мышкой внутри карточки движется мягкое свечение (через переменные --mouse-x и --mouse-y).
    Бегущая строка (VelocityMarquee)
    Текст, который бесконечно движется. Главная фишка — Skew Effect: чем быстрее пользователь крутит скролл, тем сильнее наклоняется (перекашивается) текст.
    Видео-панели (GsapPanelsShowcase)
    Секция, где проекты представлены в виде полноэкранных видео.
    При скролле панели наезжают друг на друга с разных сторон (справа, сверху, слева).
    Здесь используется pin: true, чтобы создать эффект «слайд-шоу внутри скролла».
    Горизонтальный скролл (SkillsHorizontal)
    Хотя пользователь крутит колесико вниз, блоки движутся вбок. Это реализовано через вычисление scrollWidth и трансформацию x: -totalWidth.
    Физическая песочница (PhysicsPlayground)
    Самый интерактивный блок на Matter.js:
    Создается невидимая «коробка» (стены и пол).
    Навыки (React, PHP и т.д.) превращаются в физические объекты-прямоугольники.
    Их можно хватать мышкой, швырять и сталкивать друг с другом.
    При клике срабатывает «взрыв» (приложение силы ко всем телам от центра).

4. Логика приложения (App.js)
    Состояния (State):
    lang: текущий язык.
    a11yMode: режим для слабовидящих (меняет шрифты на огромные и контрастные).
    activeProjectId: ID выбранного проекта для открытия модального окна.
    Модальное окно проекта:
        Использует AnimatePresence из Framer Motion. Когда activeProjectId не равен null, всплывает окно с детальным описанием технологий, ссылками на GitHub и Live-демо. Оно плавно появляется и исчезает с эффектом размытия заднего фона.
    Навигация:
    Анимирована так, чтобы появляться сверху через полсекунды после загрузки. Включает в себя переключатель языков и кнопку Accessibility.

5. CSS Особенности
    Noise Overlay: Поверх всего сайта наложен слой с микро-зернистостью (SVG фильтр), что придает дизайну «дорогой» журнальный вид.
    Text Gradient: Анимированные градиенты, которые постоянно переливаются.
    A11y Active: Специальный набор правил, который при включении режима доступности убирает все сложные эффекты, увеличивает текст и делает фон черным, а текст ярко-желтым.
